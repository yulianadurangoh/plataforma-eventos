# Nebula · Plataforma de eventos

Plataforma web responsive para consultar eventos académicos, tecnológicos y culturales. Incluye inicio de sesión simulado, listado de eventos, formulario de contacto y botón de WhatsApp.

## Tecnologías
HTML, CSS, Bootstrap 5 y JavaScript.

## Credenciales de prueba
- Usuario: `admin`
- Contraseña: `eventos2026`

> Autenticación simulada con fines académicos. No ofrece seguridad real.

## Estructura
- `index.html`: página de inicio.
- `login.html`: inicio de sesión.
- `eventos.html`: listado de eventos.
- `contacto.html`: formulario de contacto.
- `css/styles.css`: estilos propios.
- `js/login.js`: validación de credenciales.
