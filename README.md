# Nebula · Plataforma de eventos

Plataforma web responsive para consultar eventos académicos, tecnológicos y culturales. Incluye inicio de sesión simulado, listado de eventos, formulario de contacto y botón de WhatsApp.

## Tecnologías
HTML, CSS, Bootstrap 5 y JavaScript.

- `index.html`: página de inicio.
- `login.html`: inicio de sesión.
- `eventos.html`: listado de eventos.
- `contacto.html`: formulario de contacto.

## Desarrollo de la página de eventos

Se desarrolló la página de eventos en el archivo `eventos.html`, manteniendo el diseño y la identidad visual definida para la plataforma.

Se implementó una sección de eventos utilizando componentes de Bootstrap, organizando la información en tarjetas responsive para facilitar su visualización en diferentes tamaños de pantalla.

Cada tarjeta contiene:

- Nombre del evento.
- Descripción.
- Imagen.
- Fecha.
- Ubicación.

Se agregaron seis eventos de ejemplo relacionados con tecnología, innovación, inteligencia artificial, educación, cultura digital y emprendimiento.

También se realizó un ajuste en CSS para establecer una altura uniforme en las imágenes de las tarjetas, utilizando `object-fit: cover`, con el fin de mantener una presentación organizada.

Finalmente, se verificó el funcionamiento del inicio de sesión y la redirección hacia `eventos.html`, utilizando `sessionStorage` para mantener activa la sesión.
